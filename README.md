# Vidraçaria Siqueira — Site

Site institucional da **Vidraçaria Siqueira**, vidros sob medida em Belo Horizonte e região.

- WhatsApp: (31) 97150-9928
- Instagram: [@vidracariasiqueira_bh](https://www.instagram.com/vidracariasiqueira_bh/)
- Endereço: Avenida Jequitinhonha, 222 — Belo Horizonte/MG

## Estrutura

```
index.html   página única (HTML + CSS + JS, sem dependências)
logo.png     logo da empresa
favicon.png  ícone da aba
```

## Recursos

- Layout responsivo testado de 320 px a 2560 px (inclui celular na horizontal)
- Botões de orçamento que abrem o WhatsApp com mensagem pronta
- Formulário de orçamento que monta a mensagem e envia pelo WhatsApp
- Menu móvel, animações suaves e respeito a `prefers-reduced-motion`

## Publicar com GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
O site ficará em `https://<usuario>.github.io/site-vidracaria-siqueira/`.

## Pendências

- Substituir os espaços `[Foto …]` por fotos reais das obras
- Completar o horário de atendimento (`[DIA]`, `[HH]h`)
